# Layout Spec — Morning Briefing

## Design Principles

1. **Newspaper aesthetic** — dense, scannable, professional. Think Bloomberg terminal meets morning paper.
2. **One page, always** — 8.5×11 with 0.4in top/bottom and 0.5in left/right margins. Usable space: ~7.5×10.2 inches.
3. **Fixed relative skeleton** — header, weather, calendar, news, QR. The agent fills each section but never breaks the skeleton.
4. **Readability over density** — 10pt body minimum, 8pt for metadata. Never go below 8pt.

## Typography

- **Body font:** Helvetica Neue / Helvetica / Arial (clean sans-serif)
- **Header font:** Same, bold weight
- **Body size:** 10pt, line-height 1.4
- **Section titles:** 8pt, uppercase, letter-spacing 1.5px, gray (#888)
- **Metadata:** 8pt, gray (#999)
- **Footer:** 7pt, light gray (#ccc)

## Color Palette

- Primary text: #1a1a1a (near-black)
- Secondary text: #555 / #666
- Metadata/labels: #888 / #999
- Borders: #ddd
- Error: #c62828 (red) with #fff5f5 background
- AQI Good: #2e7d2e on #e0f7e0
- AQI Moderate: #b8860b on #fff8e0
- AQI Unhealthy: #c62828 on #ffe0e0
- Newsletter accent: #e0c060 (gold border)

## Section Layout

### Header (fixed height ~0.5in)
- Left: "The Morning Briefing" in 22pt bold
- Right: date + location, 9pt gray
- Bottom border: 2px solid black

### Weather Strip (fixed height ~0.8in)
- Flexbox row: large temp (28pt) | details column | AQI column
- Compact — this is reference info, not the main content
- Section title: "WEATHER" in 8pt uppercase

### Calendar Block (variable, typically 0.5-1.5in)
- Section title: "TODAY'S CALENDAR"
- Each event: time (bold, 80px wide) + event name + optional location in 8pt gray
- Empty state: "No events scheduled today." in italic gray

### News + Newsletter Block (fills remaining space)
- Section title: "NEWS & SIGNAL"
- Each news item: topic label (8pt uppercase) + 1-2 sentence summary + source (8pt gray)
- Left border: 2px solid #ddd (news) or #e0c060 (newsletter)
- Newsletter items appear after news items, same section or sub-section
- "Also in [newsletter]: [topics]" line for non-matching sections

### QR Code (bottom, only if overflow)
- Centered, 80×80px
- Label: "Scan for full articles and overflow content →"
- Top border: 1px solid #ddd

### Footer (fixed, minimal)
- Centered, 7pt light gray
- "Generated by Hermes Morning Briefing · [timestamp]"

## Error Rendering

When a source fails, render in its section's space:
```html
<div class="error-block">⚠ Weather unavailable: [error message]</div>
```

The section title still appears. The error block takes the section's space. No blank gaps.

## Page Fit Strategy

The agent fills sections in priority order:
1. Header (always)
2. Weather (always)
3. Calendar (always)
4. News (fills remaining space — this is the flexible section)
5. QR code (if overflow exists)

When content overflows:
- News items are ranked by relevance score
- Lowest-ranked items move to the overflow page first
- The render-check-rerender loop trims until it fits
- Max 3 trim iterations before accepting best fit

## Overflow Page

The overflow HTML page should use the same typography and color palette but without the page-size constraint. It's a scrolling web page, not a printed page.

Structure:
- Same header (date, location)
- Full news items with links
- Full newsletter sections
- No weather/calendar (those fit on the printed page)
- Back link or note: "This is overflow from your [date] morning briefing."
